# 쿵짝

폰 한 대를 가운데 두고 두 사람이 마주 앉아 겨루는 미니게임 모음.
게임 본체는 **HTML 파일 하나**. 서버·계정·네트워크 없음.

## 출시 전략

| 플랫폼 | 방식 | 상태 |
|---|---|---|
| 안드로이드 | Flutter WebView → Play 스토어 | 준비 완료, 래핑 대기 |
| 아이폰 | `web/`을 GitHub Pages에 올려 사파리로 접속 (PWA) | 준비 완료, 배포 대기 |

아이폰 네이티브 앱은 반응을 보고 나중에 판단한다.

## 실행

```bash
open web/index.html
```

폰 테스트는 파일을 기기로 옮겨 브라우저로 열면 된다.

## 게임 10개

| 게임 | 방식 | 레이아웃 | 결 |
|---|---|---|---|
| 먼저 누르기 | 노란불이 켜지면 먼저 탭 | 분할 | 반사 |
| 색깔 함정 | 글자 말고 글자 **색**을 맞히기 | 분할 | 반사 |
| 삼총사 | 네 성질이 모두 같거나 모두 다른 3장 | 공용 판 | 관찰 |
| 같은 그림 찾기 | 두 원판에 겹치는 그림 하나 | 공용 판 | 관찰 |
| 거짓말쟁이 | 내 낱말과 상대 낱말이 같은지 다른지 | 분할 | 심리 |
| 딱 다섯 | 같은 그림, 개수 합이 딱 5일 때만 | 공용 판 | 반사 |
| 거꾸로 잡기 | 눌러야 하는 색이 라운드마다 뒤집힌다 | 분할 | 반사 |
| 다른 색 하나 | 한 칸만 색이 미묘하게 다르다 | 공용 판 | 관찰 |
| 폭탄 돌리기 | 터지기 전에 상대에게 넘긴다 | 분할 | 배짱 |
| 연타 대결 | 5초 동안 더 많이 두드리기 | 분할 | 몸 |

**내기 점수는 첫 화면에서 고른다** — 1 · 2 · 3 · 5 · 7 · 10점. 기본은 3점.
정답은 딩동, 오답은 삐- 소리와 함께 화면이 흔들리고 빨갛게 번진다.
**무엇을 눌렀는지 양쪽 화면에 표시**되어 상대가 확인할 수 있다.

## 검증된 것

- 삼총사: 81장 덱의 정답 조합 1,080개 = 이론값 일치
- 같은 그림 찾기: 카드 31장, 모든 쌍(465가지)에서 겹치는 그림 정확히 1개
- 아이콘 31종 전부 자체 제작 SVG (이모지 미사용 — 기기마다 모양이 달라짐)
- 게임 10개 전부 브라우저에서 자동 조작 검사 통과 (오류 0건)
- **외부 요청 0건** — 글꼴까지 파일 안에 넣어 기내모드에서도 그대로 뜬다
