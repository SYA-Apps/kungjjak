# 쿵짝 — 타겟 한 장

> 스토어 설명 첫 3줄과 스크린샷 첫 장은 여기서 나온다. 말투·금지어는 `C:/SYA/playbook/브랜드-한장.md`.
> 2026-09-27 사용자와 정함.

```
누가 쓰나   : 폰 한 대만 있을 때 마주 앉아 잠깐 겨루고 싶은 둘 (친구·연인·형제, 13세 이상)
무엇이 불편 : ① 둘이 하는 게임은 대개 폰이 두 대 필요하고 가입·접속까지 해야 한다
              ② 카페·식당에서 기다리는 몇 분은 보드게임을 꺼내기엔 짧다
              ③ 광고와 권한 요청이 많아 켜자마자 김이 샌다
우리만의 답 : 폰 하나를 가운데 두고 위아래로 나눠 동시에 누른다. 한 판에 몇 초, 게임 10개
안 하는 것  : 인터넷 연결·계정·기록 저장이 없다 (온라인 대전·순위표 없음)
```

- 「누가 쓰나」는 친구·연인·형제 **셋을 나란히** 둔다 — 한쪽을 앞세우지 않는다(사용자 결정).
