# 아이폰 — 사파리로 먼저 가기

아이폰용 네이티브 앱은 나중이다. 지금은 웹 주소 하나로 해결한다.
`web/` 폴더가 그대로 PWA다. 홈 화면에 추가하면 앱처럼 뜨고 오프라인으로 돈다.

---

## 왜 이 방식인가

- App Store 출시는 맥 + 개발자 계정 연 $99 + 심사가 필요하다
- 아이폰 사용자는 링크만 열면 되고, 홈 화면에 추가하면 전체화면으로 앱처럼 뜬다
- 안드로이드와 **같은 파일**을 쓰므로 관리 부담이 없다

---

## GitHub Pages로 올리기

✅ **2026-09-02 배포 완료 — https://sya-apps.github.io/kungjjak/**

🚨 **`/web` 폴더는 Pages 소스로 지정할 수 없다.** Pages 가 고를 수 있는 폴더는
**루트(`/`) 아니면 `/docs` 둘뿐**이다. 예전에 이 문서에 "폴더: `/web`" 이라고
적어 뒀는데 그런 선택지가 없다. 그래서 **`web/` 안쪽만 `gh-pages` 브랜치의
루트로 올린다** — 저장소 구조는 그대로 두고 배포본만 따로 만드는 방식이다.

```bash
gh repo create SYA-Apps/kungjjak --public --source=. --remote=origin
git push -u origin master

# web/ 안쪽만 gh-pages 브랜치 루트로 (저장소 구조는 안 건드린다)
git subtree push --prefix web origin gh-pages
```

Pages 설정(`gh-pages` 브랜치 · 루트)은 위 subtree push 로 브랜치가 생기면
GitHub 이 알아서 켠다. 수동으로 하려면:

```bash
gh api -X POST repos/SYA-Apps/kungjjak/pages   -f "source[branch]=gh-pages" -f "source[path]=/"
gh api repos/SYA-Apps/kungjjak/pages --jq '.status, .html_url'   # built 가 되면 끝
```

**게임을 고친 뒤에는 두 번 올려야 한다** — `master` 에 커밋하고, 그다음
`git subtree push --prefix web origin gh-pages` 로 배포본을 갱신한다.
**subtree push 를 잊으면 사이트가 그대로다.**

⚠ 저장소가 공개라 소스가 다 보인다(그래서 올리기 전에 개인 메일·비밀번호가
없는지 확인했다). 숨기고 싶어지면 Netlify 나 Cloudflare Pages 무료 플랜을 쓰면 된다.

## 아이폰에서 설치하는 법

1. 사파리로 주소 열기 (크롬 말고 **사파리**여야 한다)
2. 공유 버튼 → **홈 화면에 추가**
3. 홈 화면 아이콘으로 실행하면 주소창 없이 전체화면

두 번째 실행부터는 서비스워커가 캐시해둔 파일로 뜨므로 **비행기 모드에서도 된다.**

---

## 아이폰에서 주의할 점

| 항목 | 내용 |
|---|---|
| 소리 | **무음 스위치가 켜져 있으면 안 난다.** 사용자가 흔히 겪는 문제 |
| 오디오 시작 | 화면을 한 번 만진 뒤에만 소리가 허용된다 (게임 시작 버튼에서 처리 중) |
| 화면 꺼짐 | 웹에서는 막을 수 없다. Screen Wake Lock API는 iOS 사파리 지원이 불안정 |
| 세로 고정 | 웹에서는 강제할 수 없다. 사용자가 회전 잠금을 켜야 한다 |

이 세 가지가 웹 버전의 한계다. 안드로이드 앱 버전에는 없는 문제이므로,
반응이 좋으면 그때 iOS 네이티브를 검토하면 된다.

## 파일을 수정했을 때

`web/sw.js`의 캐시 버전을 올려야 사용자에게 새 파일이 간다.

```js
const CACHE = 'kungjjak-v2';   // v1 → v2
```

안 올리면 기존 사용자는 계속 옛 버전을 본다. **자주 잊는 부분이다.**
