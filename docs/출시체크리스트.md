## 0. 실기기 테스트 (제일 먼저)

여기서 문제가 나오면 나머지는 다 무의미하다.

- [ ] 위쪽 절반이 180도 뒤집혀 마주 앉은 사람에게 바로 보이는지
- [ ] 탭 반응 지연이 없는지 (반응속도 게임의 생명)
- [ ] 소리가 나는지 (아이폰은 무음 스위치 확인)
- [ ] 삼총사 카드 12장이 안 잘리는지 (3열 × 4행)
- [ ] 같은 그림 찾기 원판 2개가 세로로 다 들어가는지
- [ ] 헷갈리는 아이콘 없는지 (곰↔강아지, 사과↔딸기)
- [ ] 제한 시간이 적당한지 (삼총사 6초 / 같은 그림 5초 / 다른 색 하나 5초)
- [ ] **거짓말쟁이** — 낱말을 볼 때 마주 앉은 상대에게 안 보이는지 (0.7초 이상 눌러야 뜨고,
      떼거나 4초가 지나면 저절로 가려진다)
- [ ] **딱 다섯** — 카드 두 장이 옆으로 안 잘리는지, 1.7초가 충분한지
- [ ] **다른 색 하나** — 4×4, 5×5로 넘어갔을 때 색 차이가 보이는지 (야외 밝기에서도)
- [ ] **폭탄 돌리기** — 초읽기 소리가 들리는지, 넘기는 반응이 즉각적인지
- [ ] **연타 대결** — 두 사람이 동시에 두드려도 양쪽 다 세어지는지 (멀티터치)
- [ ] 첫 화면에서 내기 점수를 10점으로 두면 점수 표시(핍)가 안 잘리는지
- [ ] **게임 중 나가기** — 귀퉁이의 집 아이콘을 0.7초 누르면 메뉴로 나가는지,
      짧게 스치거나 연타 중에는 **안 나가는지** (두 사람 다 자기 쪽 버튼으로)

테스트: `web/index.html`을 폰으로 옮겨 브라우저로 열기 (갤럭시 A23 / 아이폰)

## 1. 글꼴 임베드 ✅ 완료

`tools/embed_fonts.py` 가 Jua · Gothic A1(400·700)을 받아 실제 쓰는 글자만 남기고
woff2 로 줄여 `index.html` 안에 base64 로 심는다. CDN `<link>` 3줄은 지웠다.
브라우저에서 **외부 요청 0건 · 세 글꼴 모두 loaded** 확인.

- 현재 517자(한글 397자) / woff2 합계 136KB / `index.html` 248KB
- 둘 다 SIL Open Font License 1.1 — 임베드·재배포 가능
- ⚠ **화면 문구에 한글을 새로 추가하면 다시 돌릴 것.** 서브셋에 없는 글자는
  시스템 글꼴로 떨어져 톤이 깨진다.

```bash
python tools/embed_fonts.py
```

- [ ] 실기기에서 기내모드로 켜 글꼴이 유지되는지 최종 확인

## 4. Flutter로 감싸기 (안드로이드)

절차는 `flutter/README.md`에 단계별로 정리해두었다. 요약하면

```bash
flutter create --org com.syaapps --project-name kungjjak --platforms=android app
cp -r web app/assets/web
cp flutter/main.dart app/lib/main.dart
# pubspec.yaml 에 webview_flutter 와 assets 추가
cd app && flutter pub get && flutter run
```

- [ ] `applicationId` = `com.syaapps.kungjjak` (`com.example` 금지)
- [ ] **target API 36** (2026년 8월 기준 신규 앱 요건)
- [ ] 앱 이름 `쿵짝`
- [ ] 화면 꺼짐 방지 (`FLAG_KEEP_SCREEN_ON`) — 대결 중 꺼지면 안 됨
- [ ] INTERNET 권한 **제거** (완전 오프라인이라 불필요, 심사가 간단해짐)
- [ ] 뒤로가기 동작 확인: 게임 중 → 메뉴, 메뉴 → 종료 확인
- [ ] 릴리스 서명 키 생성 후 **원드라이브 아닌 곳에 백업** (분실 시 업데이트 불가)
- [ ] `flutter build appbundle --release` → AAB 확인

## 6. 아이폰 — 사파리 웹으로

네이티브 앱은 나중에. 지금은 GitHub Pages에 `web/` 폴더를 올려 링크로 배포한다.
`web/`은 이미 PWA로 구성해두어서 홈 화면에 추가하면 앱처럼 뜨고 오프라인으로 돈다.

- [ ] SYA-Apps 조직에 저장소 생성 후 push
- [ ] Settings → Pages → Branch `main`, 폴더 `/web`
- [ ] 아이폰 **사파리**로 열어 홈 화면에 추가 → 비행기 모드에서 실행 확인

자세한 내용과 iOS 한계는 `docs/아이폰-사파리-배포.md` 참고.

## 7. 출시 후 (선택)

지금은 광고도 결제도 없다. 반응을 보고 판단.

- 리텐션 장치: 누적 전적, 최고 기록, 게임 해금
- **AI 상대** — 혼자서도 열 수 있게 하는 가장 큰 개선. 없으면 재방문이 거의 없다
- 광고를 붙인다면 13세 이상 타겟이므로 제약은 없지만, 다운로드가 늘기 전엔 의미 없음
