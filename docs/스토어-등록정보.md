# 스토어 등록정보 (구글플레이)

Play Console 의 «기본 스토어 등록정보» 에 그대로 붙여 넣는 문구.
**글자 수는 `python tools/check_store_text.py` 로 확인한다.**

---

## ⚠ 쓰기 전에 지킬 것

- **상표명 금지.** SET·도블·할리갈리 같은 이름은 물론 **"○○ 같은 게임"** 도 안 된다.
  룰을 빌린 것은 문제가 없지만 이름을 빌리면 문제가 된다.
- **아동을 겨냥하는 표현 금지.** 타겟은 만 13세 이상이다. "아이들과", "유아" 같은 말을 쓰면
  Families 정책이 걸려 심사가 까다로워진다.
- **검색어 나열 금지.** 같은 낱말을 억지로 반복하면 정책 위반이다.
- **없는 기능을 적지 않는다.** «데이터 안전» 양식과 어긋나면 반려된다.
  이 앱은 수집·통신·권한이 전부 0이라 그대로 쓰면 된다.

---

## 앱 이름 (30자 이내)

```
쿵짝 - 둘이서 하는 미니게임
```

> 그냥 `쿵짝` 만 쓰면 두 글자라 검색에 거의 안 걸린다. 부제는 홍보 문구가 아니라
> **무슨 앱인지 설명하는 말**이어야 정책에 안 걸린다("1위", "무료" 같은 말은 금지).
> 부제 없이 가고 싶으면 `쿵짝` 만 남겨도 된다 — 법적 문제는 없다.

---

## 짧은 설명 (80자 이내)

```
폰 한 대를 가운데 두고 마주 앉아 겨루는 2인 미니게임 10개. 인터넷도 계정도 없이.
```

> 검색 결과와 앱 카드에 이 줄이 뜬다. **첫 30자 안에 «둘이서» 와 «미니게임» 이 들어가야** 한다.

### 데이터 안전 양식

전부 **«수집하지 않음»** 으로 답한다. 위치·개인정보·금융·기기ID·앱활동 어느 것도 해당 없음.
근거는 `web/privacy.html` 과 같다 — INTERNET 권한이 없어 전송이 불가능하고,
`localStorage` 를 안 써서 기기에도 남지 않는다.

### 콘텐츠 등급 (IARC) 설문

폭력·성적 내용·욕설·도박·약물 **전부 없음**. 이용자 간 소통 기능 없음(오프라인).
전체이용가가 나오지만, **타겟 연령은 별도로 만 13세 이상으로 정한다** —
아동 포함으로 잡으면 Families 정책이 걸린다.
