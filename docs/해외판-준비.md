### 정한 것

- 🔒 **언어 선택은 기기에 저장하지 않는다.** ADMIN 지시서에는 «localStorage 키 `kungjjak.` 접두어» 가 있었지만,
  한국어 방침이 «`localStorage`·쿠키를 사용하지 않는다» 고 약속하고 있고 심사 중엔 방침을 못 고친다. 그래서
  **바꾼 언어는 그 판에서만** 가고, 다시 켜면 기기 언어로 돌아온다(내기 점수 · 음악 켜기와 같은 규칙).
