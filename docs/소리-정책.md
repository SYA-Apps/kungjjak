# 소리와 무음 · 매너모드 (쿵짝)

공통 규칙(2026-10-02): 소리를 넣는 앱은 소리마다 무음 · 매너모드에서 나올지를 정해 한 줄 남긴다.

| 소리 | 분류 | 무음 · 매너모드 |
|---|---|---|
| 첫 화면 배경음악 · 대결 중 잔잔한 곡 · 점수 멜로디 | ① 사람이 켜서 듣는 소리(🔊 단추로 끄고 켠다) | **나온다**(미디어 음량). 아이폰은 처음엔 무음 스위치를 따르고(`ambient`), 🔊 를 직접 켜면 무음을 넘어 들린다(`playback`) |
| 게임 안 딩동 · 삐 · 똑딱 | ① 게임 규칙을 알리는 소리(없으면 게임이 안 된다) | **나온다** |
| 알림 · 경고 | 없음 | 알림 기능이 없다 |

- 모든 소리는 WebAudio 로 코드가 만든다(음원 파일 없음).
- 안드로이드는 매너모드가 미디어 음량을 끄지 않는다 — 이 앱은 «게임 소리 = 사람이 듣고 하는 소리» 라서 ①로 두었다(2026-09-30 사용자 확인 · 2026-10-02 공통 점검에서 «그대로»).
- 화면을 벗어나면(다른 앱으로 가면) 음악이 멈춘다(2026-10-08 · 웹 v56). 돌아오면 한 번 눌러야 다시 난다.
