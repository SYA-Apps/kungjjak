쿵짝 개인정보처리방침

시행일 2026년 9월 2일

쿵짝은 개인정보를 일절 수집하지 않습니다.

1. 수집하는 개인정보

없습니다. 아래 어느 것도 수집·저장·전송하지 않습니다.

  • 이름, 생년월일, 성별, 이메일 주소, 전화번호
  • 위치 정보, 연락처, 사진, 파일, 통화 기록
  • 기기 식별자, 광고 식별자(ADID), IP 주소
  • 앱 사용 기록, 충돌 기록, 진단 정보

이 앱은 계정이나 로그인이 없습니다. 이용자를 식별하지 않습니다.

2. 네트워크 통신

없습니다. 안드로이드 앱은 인터넷 권한(INTERNET)을 아예 요청하지 않으므로, 통신을 하고 싶어도 기술적으로 불가능합니다. 게임에 필요한 글꼴과 그림은 모두 앱 안에 들어 있습니다.

이 문서와 같은 주소로 제공되는 웹 버전(sya-apps.github.io)은 GitHub Pages 가 제공합니다. 페이지를 여는 동안 GitHub 이 접속 기록을 남길 수 있으며, 이는 GitHub 의 정책을 따릅니다. 게임 자체는 웹에서도 아무것도 보내지 않습니다.

3. 기기에 저장하는 정보

없습니다. 점수와 설정은 메모리에만 두며 앱을 끄면 사라집니다. 브라우저 저장소(localStorage·쿠키)를 사용하지 않습니다. 앱을 다시 켜면 처음 상태로 돌아옵니다.

4. 제3자 제공 · 광고 · 분석

없습니다. 광고를 넣지 않았고, 분석 도구(SDK)를 넣지 않았으며, 어떤 정보도 제3자에게 제공하거나 위탁하지 않습니다.

5. 앱이 요구하는 권한

없습니다. 카메라·저장공간·위치·연락처 등 어떤 권한도 요청하지 않습니다.

6. 아동에 관하여

이 앱은 만 13세 이상을 대상으로 합니다. 만 13세 미만 아동을 대상으로 설계되지 않았으며, 아동을 포함해 누구의 정보도 수집하지 않습니다.

7. 이용자의 권리

수집하는 정보가 없으므로 열람·정정·삭제를 요청할 대상이 존재하지 않습니다. 앱을 삭제하면 기기에서 완전히 제거됩니다.

8. 문의처

sya.apps.dev@gmail.com

9. 방침의 변경

내용이 바뀌면 이 페이지에 고칠 내용과 시행일을 함께 올립니다. 이용자에게 불리하게 바뀌는 경우에는 시행 7일 전에 이 페이지로 알립니다.
